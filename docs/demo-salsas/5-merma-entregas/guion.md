# Escenario 5 · Cuánta merma vale la pena ahorrar

Mensaje central: agrupar más baja aún más el CIP y la merma, pero atrasa dos pedidos; Fractal pone el precio a la vista y
la persona decide.

### S01 · Agrupar más
- imagen: capturas/01-opciones.png
- foco: solo cada tres días => Campañas por día + recetas pequeñas cada 3 días => Opción D
- foco: el CIP baja a sesenta y nueve horas => 68,6 h => CIP 68,6 h
- foco: la merma a tres mil ochocientos sesenta kilos => 3.861 kg => Merma 3.861 kg

> ¿Y si agrupamos todavía más? Haciendo las recetas pequeñas solo cada tres días, el CIP baja a sesenta y nueve horas y la merma a tres mil ochocientos sesenta kilos. Pero dos pedidos más llegan tarde, y su puntaje, quinientos sesenta y nueve, pierde frente a las campañas por día.

### S02 · La persona decide
- imagen: capturas/01-opciones.png
- foco: Fractal recomienda; la persona decide => ADOPTAR => La persona decide

> Fractal muestra el precio de cada kilo ahorrado en entregas. Si la planta prefiere botar menos aunque se atrasen dos pedidos, adopta esa opción; si no, la recomendada. Fractal recomienda; la persona decide.
