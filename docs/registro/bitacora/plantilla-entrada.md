# Plantilla de entrada de bitácora

Copia el bloque en [[bitacora]] (arriba de las entradas existentes) y complétalo.

```markdown
### AAAA-MM-DD · PR #N · Título corto
- **Fecha/hora (UTC):**
- **Fase del plan:** [[plan-del-proyecto]] fase X
- **Solicitado por:** (persona y cita corta de lo que pidió)
- **Qué se hizo:**
- **Commits:** `abc1234`
- **Verificación:** pruebas, CI, capturas
- **Decisiones:** enlace a [[decisiones]]
- **Conversación:** enlace a la nota del histórico
```
