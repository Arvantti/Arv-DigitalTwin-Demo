# 2026-11-20 · Eliminar advertencia de Node 20 del paso Buildx

## Solicitud y evidencia
El usuario reportó que el despliegue de #232 seguía avisando: `docker/setup-buildx-action@v3` usa internamente Node 20 y GitHub lo fuerza a Node 24. La versión de la aplicación definida en `.node-version` es 26.12.1; `actions/setup-node@v5` no modifica el runtime interno de otras acciones. La actualización previa de acciones dejó el paso Buildx pendiente y no debía haberse presentado el despliegue como si ya estuviera libre de ese aviso.

## Cambio
En el workflow manual del Acueducto se reemplazó únicamente `docker/setup-buildx-action@v3` por `@v4.4.1`. El metadato `action.yml` de esa versión declara `using: node24`; la versión anterior declara `node20`. No se modifican BuildKit, la aplicación, secretos, D1, permisos ni los pasos de prueba. Sin nuevo despliegue ni ejecución de cosimulación. La ausencia efectiva del aviso se verificará cuando se ejecute de nuevo el workflow por autorización separada.
