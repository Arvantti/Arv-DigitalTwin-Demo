# Recubridora de cama plana

Puesto interlock/coverstitch para dobladillos de manga y ruedo, operado por una persona. La simulación de eventos discretos procesa piezas mediante SAM `cycle_s`, cola finita y salida bloqueable. La escena muestra arreglo de varias agujas, áncoras, guías de hilo y movimiento del volante.

- Preset representativo: tres agujas, cinco hilos, 45 s por prenda; configuraciones dependen del submodelo.
- La ficha oficial de referencia indica puntada de cobertura y longitud de hasta 6 mm; 5.500 puntadas/min es supuesto.
- Limitaciones: no representa folder/guía, ajuste de diferencial, tensión o calidad; fallas y potencia son supuestas. Ver `FICHA.md`.
