# Inspección final de camiseta

Proceso manual con cola limitada y un tiempo de 33 s/unidad. Acepta unidades cosidas por SKU, las inspecciona y las entrega al inventario PT; retiene WIP ante salida bloqueada. No modela defectos ni rechazos por defecto para no inventar tasa de calidad. La escena muestra mesa, prendas, herramientas y una operaria inspectora.
