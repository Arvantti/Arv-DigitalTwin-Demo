# Ficha: corte textil
- Tipo: nuevo, reutilizable.
- Función: recibir rollo, extender, marcar, cortar, numerar y repartir paquetes a módulos.
- Referencia: layout conceptual de confecciones solicitado por el usuario; no se suministró equipo/foto/catálogo comercial.
- Tendido visual: 13,5 × 2,5 m (**assumed**); ciclo de 180 s/rollo (**assumed**).
- Rendimiento de referencia: 48 kits de un rollo dedicado a Polo o 60 kits de un rollo dedicado a Oversize; mezcla de rollos 50/50 (**assumed**, no se afirma consumo real).
- Flujo conectado: almacén de rollos → corte → seis colas (2 SKUs × 3 módulos), con señal de aceptación de cada cola.
- Pendiente: consumo textil por talla, marcador, ancho/gramaje, capas de tendido, desperdicio, tiempo de reposo y datos de máquina cortadora.
