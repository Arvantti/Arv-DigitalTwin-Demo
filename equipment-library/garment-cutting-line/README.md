# Línea de tendido y corte

El comportamiento recibe rollos con backpressure de los tres módulos. Procesa un rollo cada 180 s; cada rollo se asigna a un único SKU (la mezcla configurable 50/50 alterna Polo/Oversize) y entrega el lote entre tres módulos. A las seis ramas les exige readiness antes de empezar un corte; el margen de capacidad en la entrada evita desbordar los supermercados.

La geometría muestra capas extendidas, marcador, pórtico/cabezal, rollo marcador, mesa larga y HMI. Rendimiento 48 Polo **por rollo Polo**, 60 Oversize **por rollo Oversize**, cuota 50/50 y ciclo son supuestos de demostración; se sustituyen con marcador, ancho/longitud y desperdicio medidos.
